Featured project · Transit Insight

Urban Mobility Intelligence Dashboard

Transit schedules show when services run. Station reviews capture how commuters describe their trips. I brought both into Power BI so users could explore service patterns, ratings and sentiment in one dashboard.

Prepare the data

Cleaned and consolidated schedule files and station reviews using Python and Pandas, with Hadoop and Hive for storage and querying.

Classify reviews

Used NLTK to score review text and group it into positive, neutral and negative sentiment.

Build the report

Created Power BI views for operations, sentiment and peak-hour patterns. Evaluated the project through a quasi-experiment and user acceptance testing.
